# Daily Balance

A private, single-file wellness & growth tracker. Open `index.html` in any browser — no install, no server, no network requests.

## Data
Stored in the browser's `localStorage` (key `dailyBalance.v1`) on the device/browser/address where you opened it. Use **Setup → Your data → Export** for backups and to move between devices or from the local file to the hosted version (then **Import**).

## Host on GitHub Pages
1. Create a repo (e.g. `daily-balance`), add `index.html`, push.
2. Repo **Settings → Pages → Deploy from branch → main / root**.
3. Open `https://<username>.github.io/daily-balance/` on your phone → Share → **Add to Home Screen**.

The page is public, but your entries never leave your phone's browser.

Not medical advice — personal record-keeping only.
